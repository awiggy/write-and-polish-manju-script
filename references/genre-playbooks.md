# 漫剧题材方法

先确定受众和主情绪，再选择题材与叙事机制。不要把热词直接等同于完整故事。

## 题材选择框架

为每个项目确定：

1. **受众**：男频、女频或泛人群；
2. **情绪底盘**：爽、甜、虐、怕、气、暖或好奇；
3. **题材外壳**：玄幻、婚姻、末世、古装、校园等；
4. **叙事机制**：重生、系统、时间跳跃、规则、空间、身份错位等；
5. **差异变量**：只有本项目成立的人物关系、规则代价或环境压力。

推荐用“受众 × 情绪 × 题材 × 机制”描述项目，例如：

> 女频 × 好奇与虐 × 婚姻悬疑 × 时间跳跃。

## 男频常见类型

| 类型 | 核心情绪 | 连载引擎 | 常见问题 |
|---|---|---|---|
| 玄幻修仙 | 升级、压制、想象力 | 境界、资源、势力和更强对手 | 只报境界，没有选择与代价 |
| 诡异末世 | 恐惧、掌控、求生 | 新规则、新区域、资源消耗 | 规则临时增加，主角天然知道答案 |
| 系统升级 | 期待、奖励、成长 | 任务—奖励—能力—更难任务 | 系统万能，人物失去主动性 |
| 重生复仇 | 补偿、清算、改命 | 利用前世信息逐步改变局势 | 所有人降智，主角每次都精准预知 |
| 都市逆袭 | 打脸、身份反差 | 事业、财富、身份和关系升级 | 反派只会羞辱，现实权力缺少依据 |
| 全民竞技 | 荣誉、竞争、群体爽感 | 赛制、阵营、排行榜和国家压力 | 赛制不清，胜负只靠临时能力 |
| 穿越历史 | 生存、建设、权谋 | 技术、资源、阵营与制度阻力 | 现代知识无成本碾压所有人 |
| 经营种田 | 积累、治愈、掌控 | 资源循环、设施升级、群体关系 | 经营过程被旁白跳过，缺少危机 |

## 女频常见类型

| 类型 | 核心情绪 | 连载引擎 | 常见问题 |
|---|---|---|---|
| 豪门甜宠 | 偏爱、安全感、身份反差 | 关系台阶、家族利益和公开选择 | 用控制代替爱，用身份压制代替魅力 |
| 追妻火葬场 | 委屈、补偿、后悔 | 女主离开、男主付代价、信任重建 | 只让男主说后悔，没有真实偿还 |
| 婚姻家庭 | 愤怒、共鸣、重新选择 | 财产、孩子、家庭秘密和自我重建 | 主角长期被动，矛盾只靠吵架 |
| 重生复仇 | 清算、成长、夺回人生 | 证据、盟友、事业和关系重建 | 女主无所不知，反派重复犯错 |
| 萌宝家庭 | 温暖、守护、身份期待 | 亲子关系、家庭重组和秘密揭晓 | 萌宝变成万能推进工具 |
| 宅斗宫斗 | 压迫、智斗、权力变化 | 身份、证据、阵营和制度规则 | 全靠下毒陷害，规则随剧情变化 |
| 年代种田 | 生存、积累、家庭修复 | 物资、经营、村社关系和时代限制 | 空间无代价，时代环境只是装饰 |
| 女性成长 | 共鸣、独立、掌控人生 | 能力、事业、边界和关系选择 | 只喊独立口号，缺少实际行动 |
| 女性情感悬疑 | 好奇、不安、关系重估 | 证据链、记忆、身份和信任变化 | 只拖秘密，主角没有外部目标 |
| 大女主权谋 | 掌控、清算、责任 | 阵营、制度、公开代价和权力选择 | 强大等于威胁杀人，对手集体降智 |

## 泛人群类型

| 类型 | 核心抓力 | 设计重点 |
|---|---|---|
| 悬疑推理 | 问题与证据 | 公平提供线索，推理改变行动 |
| 规则怪谈 | 规则与例外 | 规则可验算，例外有来源和代价 |
| 家庭亲情 | 关系修复 | 具体亏欠、边界和行动性补偿 |
| 喜剧沙雕 | 预期反转 | 笑点服务人物目标，不破坏世界规则 |
| 校园青春 | 关系与成长 | 权力符合年龄，避免成人式万能解决 |
| 民俗志怪 | 禁忌与因果 | 民俗规则统一，不把符号当装饰 |
| 职场商战 | 利益与选择 | 用合同、岗位、资源和声誉表现权力 |
| 治愈萌宠 | 陪伴与改变 | 萌宠参与行动，不只负责可爱 |

## 叙事机制

重生、穿越、穿书、系统、空间、身份互换、失忆、时间跳跃、预知、循环、读心、规则生存和隐藏身份，都只是冲突机制。

为机制补齐：

- 主角获得什么优势；
- 优势为何不直接解决一切；
- 使用条件和代价是什么；
- 对手如何逐渐识别并反制；
- 机制如何改变人物关系；
- 中后期如何升级而不重复。

不要同时堆叠过多机制。优先保留一个主机制和一个辅助机制。

## 跨题材组合

组合时保留一个清晰情绪底盘：

- 婚姻悬疑 × 时间跳跃：用关系证据逐层重估过去；
- 荒年种田 × 空间：用资源选择检验人物责任与立场；
- 诡异末世 × 重生：用有限先知优势对抗变化后的规则；
- 宅斗 × 规则怪谈：让礼制、禁忌和生存规则互相咬合；
- 职场商战 × 身份错位：让错误身份产生真实合同和声誉后果。

每次组合必须回答：两种类型是否相互制造新冲突，而不是只把两个标签写进简介。
